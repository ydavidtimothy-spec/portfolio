# The Agents

🎧

Voice Agent

Telnyx AI

Handles: Inbound/outbound phone calls 24/7

Answers calls instantly, qualifies leads through natural conversation, and schedules meetings without human intervention.

24/7 Availability Natural Conversation Instant Qualification Calendar Booking

Prompt Framework

// Voice Agent Qualification Flow
1. Greeting: "Hi, thanks for calling [Company]. 
 How can I help you today?"

2. Qualify: "Great! Before I connect you, 
 can I ask a few quick questions?"

3. Budget: "What's your approximate budget 
 for [service]?"

4. Timeline: "When are you looking to get started?"

5. Authority: "Are you the decision-maker 
 or should I expect someone else to join?"

6. Next Step: "Perfect. Let me send you a 
 calendar link to schedule a proper call."
💬

Chat Agent

ChatGPT Models (OpenAI)

Handles: Website visitors, FAQ, lead qualification

Engages website visitors in real-time, answers questions, and captures contact information for follow-up.

Real-time Chat FAQ Automation Lead Capture CRM Update

Prompt Framework

// Chat Agent Response Logic
IF message contains greeting:
 → Send welcome message + value prop
 → Ask discovery question

IF message contains pricing question:
 → Provide general range
 → Offer to schedule call for exact quote
 → Capture contact for follow-up

IF message contains booking intent:
 → Send calendar link
 → Create CRM task
 → Trigger SMS confirmation

IF message is objection:
 → Use objection handler library
 → Offer alternative next step
 → Log for human review if unresolved

# How It Works

01

Lead Comes In

Form submission, phone call, website chat, social media — any source. Webhook captures it instantly.

02

AI Captures & Deduplicates

System checks for existing contacts, creates new record, and starts the journey timeline.

03

Agents Research Automatically

Enrichment agent scrapes company website, finds LinkedIn profile, appends contact data.

04

Lead Gets Qualified

Based on budget, timeline, authority, and need. Hot leads go to priority queue.

05

Personalized Follow-up

SMS, email, or voice — whatever the lead prefers. Content tailored to their industry/situation.

06

Meeting Gets Booked

Calendar link sent, appointment confirmed, reminders scheduled. Zero manual coordination.

07

CRM Stays Updated

Every interaction logged, every status change recorded. You have full visibility.

# Common Questions

How long does it take to build?

Full system: 1-2 months depending on complexity. Individual agents: 3-5 days each.

What if I already have a CRM?

We integrate with it. GoHighLevel, HubSpot, Salesforce, Pipedrive — whatever you're using.

Can I start with one agent?

Absolutely. Many clients start with just a voice agent or chat bot and expand later.

What happens if AI makes a mistake?

Built-in error handling, retry logic, and human escalation triggers. Nothing goes unnoticed.

Is my data secure?

All integrations use encrypted connections. Data stays in your CRM/DB. Nothing stored on third-party servers.
